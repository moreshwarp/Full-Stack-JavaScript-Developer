### Minimal LLM Reminder System

This repository now includes a tiny command line tool that stores tasks and schedules reminders using OpenAI's API for natural language parsing.

```bash
npm install
# add a reminder
node index.js add "Remind me to drink water in 5 minutes"
# start the scheduler
node index.js run
```

Set `OPENAI_API_KEY` in your environment before running.
