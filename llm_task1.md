This document outlines the first step in creating a small large language model (LLM)
based workflow that remembers tasks and sends reminders using Codex. The goal is to
build the smallest possible system that can store tasks, recall them on demand,
and trigger reminders.

## Objectives

1. **Define a storage format** for tasks so that Codex can remember them.
2. **Implement a simple script** that accepts a task description and a reminder time.
3. **Use Codex** to parse and store the task details.
4. **Schedule a reminder** that outputs the task information when the time is reached.

This foundational task sets up the structure for future enhancements such as
natural language understanding and integration with external notification services.
